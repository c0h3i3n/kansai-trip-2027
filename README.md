# Winter Kansai Trip 2027

Family travel guide for January 25 to February 1, 2027.

Website: https://c0h3i3n.github.io/kansai-trip-2027/

Static HTML, CSS, JavaScript and original SVG artwork. Published from the main branch root through GitHub Pages.

Checklist, budget and notes are stored only in each browser using localStorage. No booking IDs or travel document images are included.
